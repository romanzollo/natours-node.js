# Natours

Сайт для бронирования туров — учебный проект по курсу Jonas Schmedtmann (Node.js), который я довёл до рабочего продакшена.

Можно смотреть туры, регистрироваться, оставлять отзывы и оплачивать поездку через YooKassa. На странице тура карта с маршрутом (Яндекс.Карты). Бэкенд на Express + MongoDB, фронт — Pug-шаблоны и немного клиентского JS (собирается Parcel).

Деплой настроен под Render / Fly.io. Локально: `npm run dev:full` (сервер + watch для JS), для продакшена — `npm run build` и `npm start`.
